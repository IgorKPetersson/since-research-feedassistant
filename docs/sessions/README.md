# Session summaries

One file per working session: `YYYY-MM-DD-<slug>.md`. Each one lists what was built,
decided and found in that session, with the tickets, decisions and knowledge-base entries
it touched.

| File | Answers |
|---|---|
| `docs/sessions/*.md` | What happened in a session, and what came of it |
| `docs/HANDOFF.md` | What state the project is in, what happens next |
| `docs/DECISIONS.md` | What was decided and why |
| `docs/kb/` | What we now know about the tools and services the project uses |

Dead ends are recorded too. They are the one thing the code can never show.
